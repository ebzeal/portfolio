Project: ebzeal.online — AI Digital Portfolio & Virtual Assistant

Project description:
An AI-powered digital portfolio and virtual assistant that lets visitors explore my professional experience, technical expertise, projects, and career highlights through a conversational interface. I built the frontend with Next.js, React, TypeScript, and Tailwind CSS, and developed the backend using Python and FastAPI. The assistant integrates with OpenAI's API and maintains conversation context across user sessions. The application is designed for serverless AWS deployment using Lambda, API Gateway, S3, CloudFront, ECR, Docker, and Infrastructure as Code.

Project: MediNotes Pro — AI Consultation Notes Assistant

Project description:
An AI-powered assistant that turns a doctor's consultation notes into a professional summary, actionable next steps, and a patient-friendly email. I built the frontend with Next.js (Pages Router), React, TypeScript, and Tailwind CSS, and developed the backend using Python and FastAPI with streaming (SSE) responses. The assistant integrates with DeepSeek's LLM through an OpenAI-compatible API, and uses Clerk for authentication and subscription gating. The application is packaged with Docker and prepared for serverless AWS deployment using the Lambda Web Adapter, with the Next.js static export served from the FastAPI container.

Live at: https://6oic2tbfjxcxw4g7nv4kxg4uba0bumpz.lambda-url.us-east-2.on.aws/

1. Generative AI
2. Next.js

4. FastAPI
5. Amazon Web Services (AWS)

Other relevant skills: TypeScript, React.js, Docker, REST APIs, Tailwind CSS, DeepSeek, OpenAI-compatible API, Clerk, Amazon Lambda, Serverless, SSE/Streaming Responses.
